# 故障排查

[简体中文](troubleshooting.md) · [English](en/troubleshooting.md)

## 摘要失败时会发生什么

当单次摘要请求超时或未通过审计校验时，插件会按配置自动重试。默认在首次请求后最多追加 2 次重试，校验失败原因会作为修正反馈一并传给摘要模型。

若重试次数耗尽仍未通过，对话界面会显示失败原因与诊断文件路径。尚未提交替换的原始上下文保持不变；后台分页接续中已完成校验的页面会保存在本地，供后续继续处理。

| 提示类型 | 处理方式 |
| --- | --- |
| 摘要超时或断流 | 检查模型供应商连接状态，或在设置页适当调高等待上限与重试次数 |
| 摘要结构不完整或输出截断 | 调高摘要输出上限（`maxTokens`），或更换更适合长文本归纳的摘要模型 |
| 要求或进度校验未通过 | 查看诊断文件中的错误码与阶段信息，并按 `auditReports` 打开关联的 `audit-reject/` 记录核对拒绝候选、来源事件序号与原话片段；重试过程会自动附带该反馈 |
| 输入或单组工具消息过大 | 根据诊断中的错误码、有效配置与已采集的输入估算，调整摘要模型窗口或输入预算配置 |
| 后台分页调用额度耗尽 | 排查提示原因后，输入 `/compact` 为剩余未完成页面续批一轮调用额度 |
| 会话恢复或写隔离提示 | 保留存储目录中的事务日志与 `.rollback` 备份，重启宿主后查看恢复结果 |

## 审计误拒与自然语言边界

`PROGRESS_FACT_CONFLICT` 表示候选摘要中的任务状态或下一步动作与来源记录不一致。常规诊断文件仅记录错误码、阶段、尝试状态、有效设置、估算值与 `auditReports` 索引，不保存来源事件序号、用户原话或候选摘要正文；排查时需通过诊断文件中的 `auditReports` 打开对应的 `audit-reject/` 文件，对照其中的来源事件序号、源消息片段与候选摘要表述，确认是模型漏写最新状态还是审计规则误判。

`0.3.2-rc.2` 修复了已复现的旧快照取代与协调否定范围误判，但复杂的中文间接否定（如“并非……”“不是……而是已被取代”）仍属于已知的识别边界。若确认候选摘要与最新来源一致却仍被拒绝，欢迎附带最小复现片段、错误码与模型信息提交 Issue。对于未触发进度冲突的要求覆盖不足，引擎也会优先尝试在本地确定性重建对应要求行。

## 诊断文件位置与内容

插件默认存储在以下独立目录：

```text
<DSH_HOME>/storages/dsh-compaction-weave/
```

- `diagnostics/`：采用白名单字段记录失败阶段、错误码、每次尝试状态、耗时、返回用量、有效配置、输入估算、分页进度及关联的 `auditReports` 索引，不包含来源事件序号、会话原话或候选摘要正文。其中 `context` 下的模型路由反映会话与摘要配置路由，不代表供应商最终实际响应的模型名；`actualDshVersion` 记为 `null` 表示未可靠采集到实际运行的宿主版本，`supportedDshVersion` 则记录插件声明适配的宿主基线版本（`"0.2.2-rc.1"`）。
- `audit-reject/`：保存未通过要求或进度校验的候选摘要、实际审计文本、来源事件序号及对应源片段，可由诊断文件中的 `auditReports` 字段定位。
- `sessions/`：按会话保存已归档的原始历史事件与附件。
- `summary-config.json`：保存摘要模型路由与重试设置。

对话提示中给出的诊断路径对应当次操作，排查时优先查看该文件。若公开分享排查资料，请注意 `audit-reject/` 与会话片段包含用户原话与候选摘要正文，上传前请先检查并脱敏。

## 提交 Issue

遇到报错、压缩后回答质量明显下降，或遗忘要求与工作进度时，可在 [GitHub Issues](https://github.com/NightFrost42/dsh-compaction-weave/issues/new/choose) 选择中文或英文模板提交反馈。

日志与诊断附件均为可选。报错类问题可附上经过检查的诊断文件副本，并在正文中补充实际使用的 DSH 版本；回答质量或记忆遗漏问题可附上关键要求原话，以及压缩前后表现差异的最小对话片段。脱敏方法与隐私注意事项见 [提交问题与日志脱敏](feedback.md)。

## 更新与卸载

桌面端更新本地安装包时，先在“插件”页卸载已安装的旧版 Weave，再通过“添加插件”安装新包并重启 DSH。独立存储目录中的历史归档与摘要设置会自动保留。

命令行 profile 停止后可执行覆盖升级或卸载：

```bash
dsh plugin --profile web add /absolute/path/dsh-compaction-weave-0.3.2-rc.2.tgz
dsh plugin --profile web remove dsh-compaction-weave
```

执行完成后重新启动对应 profile 即可。
